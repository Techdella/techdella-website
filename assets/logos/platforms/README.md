# Platform logos

`td_platform_badge()` shows `<slug>.svg|png|webp` from here (copied into the theme by `npm run images`);
without a file it falls back to the prototype's text badge (§0.6).

Current files are brand marks in each platform's official colour from Simple Icons v16.34.0
(CC0; trademarks belong to their owners). Replace them with the files from each platform's own
press/brand page when the team downloads them, and follow each brand's clear-space and colour rules.

Not available in Simple Icons (the brands asked to be removed), so these show the text badge until an
official file is added: `linkedin`, `chatgpt` (OpenAI), `bing`, `copilot` (Microsoft), `slack`, `ahrefs`.

Downloaded from each brand's own website (their published site icon), Oct 2026:
`klaviyo.png` (klaviyo.com), `activecampaign.png` (activecampaign.com), `startbuddi.png`
(startbuddi.com). `brevo.svg` is from Simple Icons v16.34.0. Swap in press-kit files when the team has them.
